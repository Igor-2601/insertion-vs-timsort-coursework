# Сортировка вставками и Timsort

Курсовой проект по дисциплине «Алгоритмы и структуры данных», тема 24.
Автор: Корепанов Игорь Васильевич, Б25-191-1, ИжГТУ имени М. Т. Калашникова.

Проект содержит самостоятельные реализации на C++17, воспроизводимый генератор,
проверки корректности и устойчивости, первичные результаты и графики.

## Сборка

Нужен компилятор с поддержкой C++17: Clang, GCC или MSVC. Для CMake нужен CMake 3.16+.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Прямые команды Clang/GCC из корня проекта:

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -I include tests/test_sorts.cpp -o sort_tests
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -I include src/benchmark.cpp -o sort_benchmark
./sort_tests
./sort_benchmark results_new
```

Windows PowerShell: `./build_and_run.ps1`. Если clang++ не находится в PATH, передайте
путь: `./build_and_run.ps1 -Cxx 'C:\path\to\clang++.exe'`. Для MinGW DLL компилятора
должны быть доступны через PATH. Имя файлов на Windows оканчивается на `.exe`.
После CMake с Visual Studio программы находятся в `build/Release/`.

## Структура

- `include/sorts.hpp`: алгоритмы, рабочий буфер, счётчики.
- `include/datasets.hpp`: генератор и точная схема зерна.
- `src/benchmark.cpp`: измерения и экспорт CSV.
- `tests/test_sorts.cpp`: проверки результата, состава и устойчивости.
- `results/raw.csv`: 8 000 строк первичных измерений.
- `results/summary.csv`: средние, медианы, стандартные отклонения и счётчики.
- `results/environment.json`: характеристики реального стенда.
- `results/run_metadata.txt`: компилятор, зерно, число наборов, свойства часов.
- `figures/`: графики исследования в PNG и PDF.
- `scripts/analyze_results.py`: повторное получение сводных данных.

## Что именно реализовано

Сортировка вставками выполняет линейный поиск места и сдвигает элементы.
Timsort выделяет естественные серии, разворачивает строго убывающие участки,
удлиняет короткие серии двоичными вставками, поддерживает исправленные условия
стека (включая проверку предшествующей тройки из issue23515) и применяет galloping.

Это учебная реализация классического Timsort. В ней слияние всегда направлено
вперёд и копирует левую серию в буфер. Начальный порог galloping равен 7 и меняется
по длине скопированного блока. Она не является дословным портом CPython/OpenJDK и
не воспроизводит все их оптимизации. Рабочий буфер заранее содержит n элементов.
Сравнивать приведённые времена со встроенными сортировками других языков нельзя
без отдельного одинаково организованного эксперимента.

## Эксперимент

Размеры: 32, 64, 100, 300, 1 000, 3 000, 5 000, 10 000. Пять типов данных:
случайные различные ключи, возрастающие, убывающие, почти упорядоченные
(max(1, floor(n/100)) непересекающихся соседних обменов), 16 возможных ключей.
На каждую комбинацию приходится 100 уникальных наборов. Непересекающиеся
диапазоны значений образцов гарантируют их уникальность.

Генерация использует std::mt19937_64, базовое зерно 20261117, собственные
равномерный выбор с отбрасыванием и перемешивание Fisher–Yates. Для одинаковой
версии кода наборы воспроизводятся независимо от реализации std::shuffle.

На каждом наборе сначала измеряются вставки, затем Timsort. Измерения идут
через std::chrono::steady_clock, после прогрева, на разных копиях одного входа.
Для коротких массивов применяется пакет из max(1, floor(16384/n)) копий.
Генерация, копирование, выделение/освобождение памяти, проверка и вывод находятся
вне интервала. Цикл вызовов функций входит в пакетное время.

Счётчики включаются отдельным запуском. Сравнение — вызов сравнения двух ключей.
Запись — присваивание элементу основного или вспомогательного массива.
Локальные переменные, индексные действия и описатели серий не учитываются.
Средние в сводке рассчитаны по 100 исходным наборам, а не по числу пакетных копий.

Проверки: 15 211 наборов, каждый проверяет оба алгоритма со счётчиками и без них.
Эталон — std::stable_sort записей с исходной позицией. Также проверяются точные
счётчики вставок для возрастающего и убывающего входа.

Время зависит от компьютера, оптимизации и фоновой нагрузки. Исходные измерения
относятся к AMD Ryzen 5 5600X, Windows 11 x64, Clang 23.1.5 и флагу -O2.
Повторный запуск следует писать в новый каталог, чтобы сохранить исходные данные.

```sh
python scripts/analyze_results.py results_new
```
